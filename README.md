# Nexora

### Modern RTL E-Commerce Management Dashboard

Nexora is a modern and responsive **Persian RTL e-commerce management dashboard** designed to provide a clean and intuitive interface for managing online stores, orders, customers, products, transactions, reports, notifications, and store settings.

The project focuses on creating a realistic administrative experience with a modern UI, responsive layouts, configurable appearance, and organized management modules.

---

## ✨ Features

### 🏠 Dashboard Overview

A centralized overview of the store's most important metrics:

* Today's sales
* New orders
* Total customers
* Product inventory
* Sales overview and charts

### 🛒 Order Management

Manage and track orders through different stages:

* All orders
* Pending payment
* Processing
* Shipped
* Cancelled

### 👥 Customer Management

A dedicated customer management system including:

* Customer list
* New customers
* Active customers
* Customer details

### 📦 Product Management

Manage the store's products and inventory:

* All products
* Add product
* Categories
* Inventory management
* Low-stock products

### 💳 Transaction Management

Track and organize payment transactions:

* All transactions
* Successful transactions
* Failed transactions
* Pending transactions
* Refunds

### 📊 Reports & Analytics

Organized reporting sections for:

* Sales reports
* Order reports
* Customer reports
* Product reports

### 🔔 Notifications

Centralized notification management for:

* New notifications
* Order notifications
* Payment notifications
* System notifications

### ⚙️ Settings

A dedicated settings system with:

* Account settings
* Appearance customization
* Store settings
* Payment settings
* Notification settings
* Security settings

## 🎨 UI & UX

Nexora is designed with a strong focus on usability, visual consistency, and responsive interaction.

### RTL & Persian Interface

The entire interface is designed for **Persian users** with a native right-to-left layout.

* Full RTL layout
* Persian interface
* Persian-friendly navigation
* Right-to-left content structure
* Consistent spacing and alignment

### 🎨 Appearance Customization

Users can customize the dashboard appearance through:

* Accent color customization
* Light mode
* Dark mode
* Animation preferences

### 📱 Responsive Design

The interface is designed to adapt across different screen sizes:

* Desktop
* Tablet
* Mobile

The goal is to provide a consistent and usable dashboard experience regardless of the device.
